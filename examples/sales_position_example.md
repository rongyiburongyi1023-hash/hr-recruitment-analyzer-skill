# 案例二：企业客户销售岗位分析

> 本案例为教学用虚构场景，目标数字和区域安排需由实际组织确认。

## 输入

```yaml
task_type: job_analysis
job_title: 企业客户销售顾问
business_context: 为中小企业提供人力资源SaaS；销售团队处于新区域拓展阶段，向区域销售经理汇报
job_objective: 开发目标区域企业客户，完成从商机识别到签约及交接的销售闭环
responsibilities:
  - 开拓客户并完成销售目标
  - 产品演示和商务谈判
  - 维护客户关系
requirements:
  - 3年以上销售经验
  - 沟通能力强，抗压能力强
performance_expectations: 试用期内建立有效商机管道；正式销售目标待确认
constraints: 需要区域内客户拜访
```

## Skill 处理

1. 将笼统的“完成销售目标”拆为目标客户开发、需求诊断、方案推进、商务转化和交接质量。
2. 审查“三年以上经验”是否为必要门槛，建议以完整销售周期证据为主。
3. 把“沟通强、抗压强”改写为可观察的顾问式销售和目标管理行为。
4. 保留未确认的配额、客单价、周期和出差频率，不为案例补造数据。

## 输出结果

### 岗位目标

面向目标区域的中小企业识别并发展有效商机，通过业务需求诊断、解决方案呈现和多方决策推进实现签约，并将客户信息完整交接至实施或客户成功团队。

### 关键产出

| 关键产出 | 成功表现 | 建议指标/证据 |
| --- | --- | --- |
| 健康的商机管道 | 目标客户清晰，商机阶段和下一步行动真实可追踪 | 有效商机数量、管道覆盖、阶段转化 |
| 达成签约结果 | 能推进决策链并控制销售周期 | 签约额、赢单率、销售周期 |
| 方案与需求匹配 | 能识别业务痛点并呈现相关价值 | 需求记录、方案质量、客户反馈 |
| 高质量销售交接 | 承诺、范围与客户信息准确完整 | 交接完整性、后续团队反馈 |

### 核心职责

| 职责领域 | 主要职责 | 对应产出 |
| --- | --- | --- |
| 客户开发 | 定义目标客户，通过合适渠道触达并验证商机 | 健康的商机管道 |
| 需求与方案 | 访谈关键角色，识别问题、影响和采购标准；组织演示 | 方案与需求匹配 |
| 商务推进 | 管理决策链、异议、谈判和内部资源，推动签约 | 达成签约结果 |
| 预测与交接 | 更新商机信息和预测，向交付团队传递范围及承诺 | 高质量销售交接 |

### 任职资格

**必备条件**

- 有开发企业客户并推进完整或主要销售阶段的事实性经历。
- 能通过提问识别客户业务问题、影响、决策角色和采购过程。
- 能管理多条商机的阶段、优先级、下一步行动和风险。
- 能进行清晰的方案呈现及商务沟通，并准确记录客户承诺。
- 能满足经确认的区域客户拜访要求。

**优选条件**

- 有 SaaS、HR 科技或面向中小企业的顾问式销售经验。
- 有新区域或新产品市场开拓经验。

### 能力模型

| 能力 | 定义 | 关键行为 | 建议验证方式 |
| --- | --- | --- | --- |
| 商机开发 | 持续识别并验证有价值的销售机会 | 定义客户画像；多渠道触达；及时淘汰无效商机 | 行为面试 + 管道案例 |
| 需求诊断 | 理解客户问题及决策逻辑 | 追问影响；识别角色；验证优先级与预算过程 | 角色扮演 |
| 商务推进 | 推动复杂关系和异议形成决策 | 制定下一步；处理异议；协调资源；守住承诺边界 | 行为面试 + 情境题 |
| 目标与过程管理 | 用过程数据管理结果风险 | 维护 CRM；复盘转化；准确预测并调整行动 | 工作样本 |

### 面试评价标准示例

| 维度 | 建议权重 | 达到要求的证据 |
| --- | ---: | --- |
| 商机开发 | 25% | 能说明目标客户选择、触达方法、资格判断和转化数据 |
| 需求诊断 | 25% | 能通过结构化提问连接业务问题、影响与解决方案 |
| 商务推进 | 25% | 有识别决策链、处理异议并推动明确下一步的实例 |
| 目标与过程管理 | 15% | 能用管道数据预测风险、确定优先级并调整行动 |
| 协作与交接 | 10% | 有控制承诺边界并完成内部交接的具体证据 |

### 假设与待确认项

- “3 年以上销售经验”暂不作为绝对门槛；需由业务方说明其与销售复杂度的关系。
- 需确认目标客户规模、平均客单价、销售周期、配额和管道覆盖要求。
- 需确认线索来源中自拓与市场分配的比例。
- 需确认拜访区域、频率以及差旅支持政策。
- 需确认签约后客户维护与客户成功团队的职责边界。
